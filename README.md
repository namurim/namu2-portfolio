# yerim_cv

한예림의 포트폴리오 웹사이트입니다. HTML·CSS·JavaScript로 구성되어 별도 빌드 없이 사용할 수 있습니다.

## 구성

- HTML: Home, About Me, Research Interest, Publication, Project, Paper Notes
- assets/css/: 스타일
- assets/js/: 팝업, 영상 재생 등 화면 기능
- assets/images/: 사진 및 프로젝트 이미지
- assets/documents/: CV 등 문서
- scripts/preview.py: 로컬 미리보기 서버

## 실행과 수정

start-preview.cmd를 실행하면 로컬 미리보기를 엽니다. Python이 필요합니다.
본문은 각 HTML에서, 디자인은 assets/css/에서 직접 수정합니다.
예전 페이지 생성·수정용 일회성 스크립트는 삭제했습니다.
