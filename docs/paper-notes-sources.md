# Paper Notes sources

Summaries are based on the papers, not the presentation videos. Videos have not been watched, downloaded or transcribed.
Record dates are inferred from the date prefixes visible in the supplied filename screenshot, not publication dates.

- Minitron: https://arxiv.org/abs/2408.11796
- Test-Time Scaling: https://arxiv.org/abs/2502.06703
- Adapting While Learning: https://arxiv.org/abs/2411.00412
- rStar2-Agent: https://arxiv.org/abs/2508.20722
- Deep Researcher: https://arxiv.org/abs/2507.16075

For playback, set each entry's video_url in data/paper-notes.json to its individual Google Drive file sharing URL, then run scripts/paper_notes.py.
The folder URL does not identify individual videos. No fake video IDs are used.
Video iframes are created with no src and connected only when a visitor opens a dialog. Closing the dialog removes src to stop playback.
The original file title Deep Research with Test-Time Diffusion is normalized to the paper title Deep Researcher with Test-Time Diffusion.
